화면마다 A · B · C 중 하나를 눌러 고르고 「결과 복사」. 위 1280 / 1600 단추로 모든 틀이 바뀝니다(주소 ?w=1600 또는 #w1600도 됨). 추천 = 제 추천(처음 고른 상태). 바탕은 지금 게임을 그 폭으로 찍은 화면이고, 위에 얹은 것만 시안입니다. 그대로 두는 것: 손가락 · 강조 테두리(정해짐), 상단 가운데 알림 띠, 유나 알림(YunaToast), 말풍선 자리 규칙(짚는 곳 · 창 내용을 덮지 않음, 떨어지면 꼬리 숨김 + 이름표). 세 안은 색이 아니라 서 있는 방식이 다릅니다: A = 짚는 곳에 붙는 쪽지, B = 유나가 직접 말함, C = 화면 끝 대사창.
