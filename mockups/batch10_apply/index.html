움직임 (게임 녹화 · 적용 후)

게임 화면을 프레임마다 찍어 실제 시각대로 묶은 mp4(yuv420p · tv 범위)입니다. 설정: 탭 넘김 · 스위치. 만든 사람들: 흐름 → 누르고 있기(빨리) → 끌어 넘김 → 「끝으로」.

시안과 다른 점 · 그대로 둔 것

  • D10-1 톱니 구슬: 펼침 메뉴(more_box)를 없애고 오른쪽 위 금테 구슬 하나를 누르면 바로 설정이 열립니다. 시안의 금빛 톱니 그림과 라벤더 이름 띠를 그대로 옮겼습니다. 「개발」 렌치 구슬은 디버그 빌드 + skywhale/dev_cheats에서만 만들어지고, 출시 판에는 노드가 없습니다. 시안의 빨간 점은 설정에 「할 일」이 생기는 경우가 없어 넣지 않았습니다(빨간 점 = 할 일 규칙).
  • D10-2 견출지 탭: 게임 · 알림 · 절전 · 계정 세 탭, 판은 화면 가운데(플레이 테스트 1차 #39로 시안의 오른쪽 유나 전신은 뺌). 계정 탭의 「준비 중」 넷(계정 연동 · 고객 문의 · 쿠폰 · 약관)은 따로 늘어놓지 않고 「준비 중이에요」 카드 하나에 묶었습니다. 누르면 유나 알림이 뜨고, 없는 기능을 있는 척하지 않습니다. 만든 사람들 · 앱 버전만 진짜 줄로 남겼습니다.
  • D10-3 흐르는 크레딧: 누르고 있으면 빨리 흐르고, 끌거나 휠로 넘기며, 「끝으로」 단추로 바로 끝에 갑니다. 고래 아래 구름은 회색 평면 대신 위가 밝고 아래가 라벤더로 그늘지는 부피 셰이더로 그렸습니다. 라이선스 전문은 종이 시트로 열립니다.
  • D10-4 개발 메뉴로만: 출시 판 설정에서 「소리 설정」 줄과 SoundPanel 입구를 없앴습니다(볼륨 두 줄은 게임 탭에 그대로). 사운드 테스트 · 진단은 개발 클립보드 창에만 남습니다.
  • 뒤로 버튼: 설정 · 만든 사람들 · 라이선스 종이 · 개발 클립보드 모두 한 번에 한 겹씩 닫힙니다(back_button_check 73/0).
