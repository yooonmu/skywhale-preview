게임 안 시험 장면(scenes/test/tone_ab/)을 실제 전투 · 실제 데이터 · 실제 글꼴 · 실제 셰이더로 찍었습니다. 구조는 지금과 같고 재질 · 글자 · 아이콘 · 움직임만 다릅니다. 이미지를 누르면 크게 봅니다.

A 2차에서 바뀐 것

  • 진짜 유리: 뒤 전투를 흐리게 떠 와 가장자리에서 굴절, 고운 서리 결, 위에 고이는 빛, 빛 받는 쪽 맑은 1px 테, 아래 두께 빛 줄, 왼쪽 위 → 오른쪽 아래로 짙어지는 라벤더. 상세 화면은 그림까지 그린 뒤 한 번 더 떠서 정보 판 · GROWTH 패 · 칩이 그림을 비춥니다(층마다 깊이).
  • 다듬은 금선: 잘린 귀 + 귀 위 작은 마름모 구슬, 위쪽 겹 금선, 머리 줄 가운데 겹 마름모, 스테이지 판 양옆 날개, 창 귀퉁이 겹 꺾쇠 — 금은 모두 머리카락 굵기 선.
  • 글자 단계: 숫자는 발로 세미 컨덴스드(전투력 46 · 공격력 32 · 스탯 19), 영문 작은 대문자 이름표(STAGE · GROWTH · COMBAT POWER · STATUS), 프리텐다드 굵기 네 단계.
  • 상세 오른쪽 판: 흰 판 대신 밝은 서리 유리 + 크림 숫자 카드 + 아이콘 달린 여섯 줄 + 파인 장비 칸 넷(이름 · 비어 있음) + 탭은 한글/영문 두 줄 에나멜 조각.
  • 아이콘: 얇은 선 아이콘 → 왼쪽 위 빛 · 그라데이션으로 채운 33종(메뉴 · 설정 · 색 지도 팔레트 · 이야기 책 · 바람 · 고래 · 보스 왕관 · 스탯 · 장비 칸). 재화 그림은 연기 유리 구슬 자리에.
  • 버튼 재질과 움직임: 에나멜(사선 결 · 안쪽 빛 · 안쪽 금선) / 흰 자기 / 유리 칩, 누르면 1.5px 내려앉고 그림자가 줄며 놓으면 금선 빛 한 바퀴. 창이 열릴 때 · 탭을 바꿀 때도 금선 빛, 큰 유리 판엔 11–15초마다 아주 옅은 빛이 지나갑니다. 튀는 움직임은 없습니다.
  • 모바일 부담: 유리 한 점에 1/8 밉 9번 읽기, 화면 복사 HUD 1번 · 상세 2번, 아이콘은 쓰는 크기로 한 번 구워 캐시. 프레임마다 새로 만드는 것은 없습니다.

아이 상세 (A 2차는 여는 순간부터 · 탭 전환 · 레벨 업 누름) · 영상 (1280)

공용 UI 키트로 옮길 부품 (A를 모든 화면에 깔 때)

판 재질 하나 (tone_glass.gdshader)유리(panel · chip · sheet · deep 연기 유리)와 단단한 칠(primary 에나멜 · secondary 흰 자기 · cell 크림 종이 · well 파인 칸 · tag)을 한 셰이더로. 뒤 화면 1/8 밉 흐림 + 가장자리 굴절 + 서리 결 + 위 빛 고임 + 빛 받는 쪽 1px 맑은 테 + 아래 두께 빛 줄. 높이 elev 0–3 = 넓은 빛 그림자 + 접지 그림자 두 겹.
모양 · 금선 규칙모서리 4–8px + 오른쪽 위 · 왼쪽 아래 잘린 귀(notch). 금은 1px 선만: 판 · 정보 판 · 주 버튼에만, 위쪽에만 옅은 겹 금선, 잘린 귀 금선 위 작은 마름모 구슬. 작은 칩은 금 없이 맑은 유리 테.
버튼 세 단계주 버튼 = 라벤더 에나멜(사선 결 · 아래 되돌아 나오는 빛 · 안쪽 금선), 보조 = 흰 자기 + 옅은 금선, 칩 = 유리. 누르면 판이 1.5px 내려앉고 그림자가 줄며, 놓으면 금선을 따라 빛이 한 바퀴(flash).
재화 칩유리 칩 + 연기 유리 구슬 자리(금 머리카락 테)에 재화 그림 + 숫자 글꼴 오른쪽 맞춤 + 작은 에나멜 (+).
머리 띠 · 스테이지 판연기 유리 번호 칸(영문 작은 대문자 + 큰 숫자) + 이름 + 보스 칸까지 막대 + 양옆 금선 날개(자리 있을 때만).
탭 · 단위 스위치파인 홈 위를 미끄러지는 에나멜 조각(0.26초 감속), 한글 + 영문 작은 대문자 두 줄, 바꿀 때 금선 빛.
숫자 카드 · 정보 줄크림 종이 칸 위 큰 숫자(46) + 둘째 숫자(32 라벤더) + 영문 이름표 / 줄 = 파인 구슬 아이콘 + 이름(14 회보라) + 값(숫자 글꼴 19, 오른쪽) + 가는 라벤더 줄.
금선 장식 Ornrule(가운데 겹 마름모) · wing · corner · crest · vrule — 판마다 한 가지, 머리카락 굵기.
아이콘 세트 (SVG 33종)48 격자 · 왼쪽 위 빛 · 남보라 그라데이션 + 크림 조각 · 금은 0.9px 선만 · 화방 도구(팔레트 · 책 · 붓 · 유리 모래시계). 쓰는 크기로 한 번 구워 캐시.
글자 단계프리텐다드 Medium / SemiBold(기본) / Bold / ExtraBold(제목), 숫자 = 발로 세미 컨덴스드 SemiBold · Bold, 영문 작은 대문자 = 같은 글꼴 자간 +2, 이름만 고운바탕. 최소 13px.
막대 · 고리막대 = 파인 홈(위 그늘 · 아래 빛) + 끝 빛 눈금, 고리 = 바깥 금 머리카락 테 + 머리 빛 점.
