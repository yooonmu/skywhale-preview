지금은 실패 · 도시락 · 하늘 이벤트 · 모험 시작이 모두 같은 크림 띠(hud.gd banner, 1.4초)로 화면 가운데를 지나가고, 눌러도 아무 데로도 가지 않습니다. 이야기 열림 · 분교 끝은 유나 말풍선(YunaToast)으로 떠서 「내가 한 일」 반응과 섞입니다.

알림 vs 완료 알림(YunaToast, 확정 C) — 역할 나눔

완료 알림 = 내가 누른 것의 대답(추천 편성 · 새 덱 탭 · 되돌림 · 신화 1명 제한). 누른 자리 옆, 얼굴 원 + 말풍선, 버튼 없음, 2.4초.
알림 = 내가 누르지 않았는데 생긴 일. 정해진 한 자리, 갈 곳 버튼. → 지금 YunaToast로 뜨는 이야기 열림 · 분교 끝은 알림으로 옮김을 제안합니다 (확인 필요).

알림이 아닌 것 (다른 담당)

잠긴 버튼 누름 = 잠김 알림(LockGate) · CLEAR · 폭주 · 순풍 띠 = B3 · 보스 등장 = 보스 경고 A · VS · 승패 = 대결(아래 2) · 모험 시작 띠 = 모험 C.
쌓임 규칙(세 안 공통): 한 번에 하나만 크게, 높음은 앞으로 끼어듦, 같은 종류는 합침(「빛물감 +5」 두 번 → +10).

A 「위 가운데 알림 판」 늘 같은 자리 · 아이콘 + 동사 + 갈 곳 버튼

위 판들 바로 아래(보스 때는 보스 판 아래) 가운데 한 자리. 세기는 재료로 구분: 낮음 = 작은 남색 유리 알약, 보통 = 크림 판 + 종류 구슬 + 라벤더 버튼 + 줄어드는 금 실선, 높음 = 남색 판 + 붉은 구슬 + 금 버튼과 화면 가장자리 붉은 숨. 쌓이면 뒤에 판 모서리가 비치고 「다음 N개」. 비용: 눈이 전투(오른쪽 아래)에서 위로 한 번 올라가야 함.

B 「오른쪽에서 밀려드는 카드 더미」 눈이 머무는 쪽 · 여러 개를 동시에

눈이 머무는 오른쪽(적 · 스킬 원판 위)으로 카드가 밀려 들어옵니다. 왼쪽 끝 세기 색 띠(회보라 · 라벤더 · 금 · 붉음)와 카드 크기로 세기를 알리고, 새 카드가 위, 앞의 것은 작아져 아래로. 놓친 것은 화면 끝 「알림」 탭에 숫자로 남아 나중에 열어 봅니다. 비용: 오른쪽 적 일부를 가림.

C 「유나가 편지로 전해 줌」 사람이 알려 주는 느낌 · 가장 눈에 띔

보통 · 높음은 유나가 뱃머리 앞에 톡 올라와 편지 판을 내밉니다(기쁨 / 놀람 그림). 편지 왼쪽 금테 봉인 구슬이 종류, 오른쪽이 갈 곳 버튼. 낮음은 몸 대신 유나 얼굴만 그 자리에서 빼꼼(도시락은 보호막 옆, 퀘스트 완료는 퀘스트 판 옆). 완료 알림(얼굴 원 + 말풍선, 버튼 없음)과 달리 몸 전체 + 편지 + 버튼이라 둘이 헷갈리지 않습니다. 비용: 화면 가운데를 가장 많이 가림.

2 · 대결 — 줄다리기

지금 게임과 공통 규칙

지금은 오른쪽 위 이름판의 작은 막대 하나라, 20초 동안 누가 이기고 있는지 · 기세가 어느 쪽인지 · 역전 순간이 보이지 않습니다.

  • 힘 = 양쪽 남은 힘(고래 보호막 + 남은 아이)의 비율. 기세 = 최근 2초 동안 어느 쪽으로 움직였나(화살 · 흐름 방향). 역전 = 가운데 선을 넘는 순간 금빛 「역전!」. 남은 시간 = 20초(duel_scene.gd), 5초부터 붉음.
  • 세 안 모두 항해 부품(퀘스트 · 메뉴 판 · 순풍 · 복귀)은 접고, 숨결은 잠김 가 「대결 중 쉼」, 스킬 원판 · 강화 · 자동은 그대로. 「건너뛰기 ▶▶」는 오른쪽 위 크림 꼬리표.

A 「물감 밧줄」 이어진 힘 · HUD 판 안에서 읽힘

위 가운데 남색 판 안의 밧줄 — 우리 쪽은 금 · 라벤더 · 하늘 물감이 꼬인 줄, 상대 쪽은 잿빛 줄. 매듭(금테 구슬) 자리가 힘이고 그 안에 남은 초. 당기는 쪽으로 줄무늬가 흐르고 ››› 화살이 기세. 역전 때 줄이 팽팽하게 떨리고, 이기면 잿빛 줄이 끊어지며 조각이 튐. 양 끝 점선 칸 = 거의 끝.

B 「색 영토」 하늘 전체가 줄다리기 · 가장 크게 느껴짐

두 고래 사이 하늘 자체가 경계: 우리 쪽은 원래 색, 상대 쪽은 잿빛으로 바랩니다. 경계선은 하늘 → 라벤더 → 금 물감 붓질이 밀고 당기며 물감 방울이 튀는 쪽이 기세. 위에는 「우리 색 62%」 · 「잿빛 38%」 판과 경계를 따라다니는 초 구슬만. 이기면 하늘 전체가 물들고, 지면 잿빛이 우리 고래까지 덮습니다. 비용: 화면 처리가 가장 무거움(가장자리 마스크 + 흑백).

C 「깃발 칸 뺏기」 끊어진 칸 · 점수처럼 6 : 4

위 가운데 기운 칸 10개(우리 = 하늘 띠 + 별, 상대 = 잿빛) + 양 끝 결정 칸(휘장). 앞선 쪽이 칸을 하나씩 뒤집으며(금빛 번쩍) 양쪽 금테 구슬에 점수가 뜹니다. 「3칸 연속!」이 기세, 가운데 금선을 넘으면 「역전!」, 결정 칸까지 남은 칸 수가 위기 · 기회. 비용: 힘이 10% 단위로만 보임.
