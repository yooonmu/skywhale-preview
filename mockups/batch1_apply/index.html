1. 메뉴 틀 A — 오른쪽 세로 책갈피 (여섯 허브 공통)

책갈피 = 종이 띠 두 겹(그림자 · 접힌 끝) + 금빛 가는 테, 고른 책갈피는 왼쪽으로 솟고 허브 색 리본이 됨. NEW · 빨간 점은 책갈피 귀에, 잠긴 허브는 자물쇠 + 흐림(LockGate). 바탕은 허브마다: 아이들 수채 종이 · 편성 짙은 갑판 · 소환 밤 도서관 · 모험 항해도 · 분교 칠판 · 상점 진열장.

2. 아이들 목록 C — 큰 미리보기 + 목록

갑판 아이 먼저(자리 번호), 빨간 점 = Menus.can_grow, 속성 거르기, 긴 이름은 칸에 맞춰 줄임. 한 번 누르면 왼쪽 큰 그림이 그 아이로 바뀌고, 고른 칩 · 큰 그림 · 「상세 보기 ›」를 누르면 상세.

3. 아이 상세 — 패널 아래 키우기 줄 A

레벨 업(꾹 누르면 계속) · 승급 · 각성 N단계가 한 줄. 「성장 Lv · 영구 | 항해 Lv · 복귀하면 처음부터」와 「각성 단계별 효과」 판은 그대로.

4. 장비 목록 A — 마네킹 + 서랍

천 무대(조명 · 바닥 빛) 위 마네킹에 네 칸, 칸 테 = 등급 색(GradeStyle), 낀 칸은 빛이 숨 쉬고 위에 「장비 강화」 칩. 오른쪽 나무 서랍은 부위 손잡이를 누르면 열리고(미끄러짐 애니), 아래 세트 알약 · 도감 · 일괄 연성.

5. 각성 A — 별자리

별자리 선이 차례로 그려지고 각성한 별이 단계마다 켜짐. SS = 속성 색 빛, 신화 = 무지개, 다음 별은 점선 고리로 숨 쉼. 하늘 · 성운 · 별똥은 셰이더 겹 + 입자.

6. 연성 결과 A — 작업 일지 한 장

줄마다 「재료 4개 ▶ 새 장비」를 잉크 도장처럼 찍음(재료는 밀리며 바램, 새 장비 톡 + 빛). 등급 상승 = 금빛 형광펜 + 「등급 상승!」 + 빛 터짐, 도감 NEW, 연쇄 = 「×16 ▶ ×4 ▶」. 연성할 것 없음 = 가장 가까운 묶음 n / 4. 작업대 덧칠로 잠재 등급이 오르면 같은 종이(「잠재 보랏빛 ▶ 금빛」 + 새 잠재 세 줄). 아무 데나 누르면 끝까지, 「연출 짧게」를 켜 두면 바로 결과.
