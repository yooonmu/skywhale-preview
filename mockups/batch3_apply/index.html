D3-1 · 학교로 복귀 확인 — 고래 그림 카드

잎 모양 모서리 크림 카드(금은 바깥 · 안쪽 실선만). 그림 창 = 저녁 하늘 셰이더 + 구름바다 두 겹(흐름) + 해 쪽 테두리빛 고래(둥실) + 바람 줄기 · 빛 알갱이, 아래는 물결선으로 종이에 녹아듦. 받는 진주는 숫자가 굴러 오르고, 처음부터 다시 출항하는 것 · 지금 STAGE → 분교 점선 항로.

D3-2 · 복귀 불가 (짧은 항해) — 유나 한마디

창 없이 YunaToast 자리(전투 중 = 위 HUD 아래 가운데, 누르기 통과)에 놀란 유나 + 크림 말풍선(뾰족 꼬리 · 「유나」 이름표) + 진주가 모이는 STAGE까지 칸 줄. 「STAGE n」은 실제 진주 계산으로 찾습니다(이 계정은 22). 누른 「복귀」 버튼이 살짝 도리질.

D3-4 · 귀환 보상 — 기록 리본

제목 아래 두 겹 비단 리본(양 끝 제비 꼬리)이 왼쪽에서 펼쳐짐: 「이번 항해 STAGE n까지」. 이번 항해가 기록 끝이면 산호빛 「최고 기록」 꼬리표 톡 + 별빛. 이 복귀로 복귀 퀘스트가 끝나면 라벤더 인장이 쾅 + 「복귀 퀘스트 완료 · 보상 · 퀘스트 칸에서 받아요」(받은 뒤 안내가 퀘스트 칸을 짚음).
