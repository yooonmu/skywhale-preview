D10-2 · 설정 scripts/settings_panel.gd · 방향 「분교 교무수첩」 — 켬 / 끔이 물감 스위치

줄 · 글 · 값은 settings_panel.gd 그대로: 게임(배경 음악 70% · 효과음 80% · 스킬 컷신 · 화면 프레임 60 / 30 · 절전 · 방치 절전 3분 · 알림 · 언어 한국어) / 계정 · 지원(계정 연동 · 고객 문의 · 쿠폰 입력 · 이용약관 · 개인정보 처리방침 = 「준비 중」, 만든 사람들, 앱 버전 v0.6 · 개발 빌드). 「소리 설정 ▸」 줄은 위 두 볼륨 줄과 내용이 같아 세 안 모두 뺐습니다(D10-4 PD 결정에 따라 「소리 듣기」 줄을 다시 넣을 수 있음). 바뀐 값은 바로 반영 · 저장(지금 동작 그대로).

상태

지금

흰 판 두 칸 + 산호 슬라이더 + 라벤더 / 크림 네모 단추. 모든 칸이 같은 단추라 무엇이 켜져 있는지 색 차이로만 읽히고, 「준비 중」 넷이 회색 단추로 줄지어 있어 「고장 난 판」처럼 보임. 정보는 다 있지만 「분교 수첩」 같은 물건 느낌이 없음.

A · 교무수첩 두 쪽 — 가죽 겉장에 펼친 왼쪽 「게임」 · 오른쪽 「계정 · 지원」 추천

비용: 지금 두 칸 구조 그대로 판만 바꿈(겉장 · 종이 셰이더 + 물감 스위치 부품) → 노드 이름 · 검사(줄이 판 안 · 겹침 없음) 그대로 통과. 1600에서도 같은 크기로 가운데.

정직한 평: 방향 「교무수첩」을 가장 그대로 살리면서 지금 정보 배치를 하나도 안 바꿔 위험이 가장 적음. 줄마다 그린 그림 아이콘 + 물감 붓질 덕에 켜진 값이 한눈에 보임. 약점: 한 화면에 줄이 13개라 글이 많고, 오른쪽 쪽 아래가 스티커 말고는 비어 보임.

B · 견출지 탭 — 한 번에 한 주제, 큰 줄 + 옆에서 지켜보는 유나

비용: 탭 3개 + 줄 높이 88px로 다시 짬, 유나 전신 그림(assets/brand/title_yuna.png) 재사용. 검사의 「한 화면에 모든 줄」 확인을 탭마다로 바꿔야 함. 「알림」 탭은 줄이 둘뿐이라 절전을 같이 둠.

정직한 평: 누르기 쉬운 큰 줄 · 큰 스위치라 손가락 조작이 가장 편하고, 유나가 있어 「분교」 분위기가 가장 따뜻함. 약점: 계정 탭은 6줄 중 4줄이 「준비 중」이라 출시 직후엔 빈 탭처럼 보이고, 탭을 오가야 해 「무엇이 켜져 있나」 전체를 한 번에 못 봄.

C · 카드 격자 — 펠트 게시판에 붙인 설정 카드 13장

비용: 카드 판 1종(종이 + 테이프) + 그림 아이콘 13개. 1600에서도 같은 격자. 항목이 늘면 줄이 하나 더 생겨 세로 밀기가 필요.

정직한 평: 그림이 앞에 서서 글을 덜 읽어도 됨 — 「무엇이 있는지」 훑기는 셋 중 가장 빠름. 「준비 중」 카드는 바랜 종이 + 자물쇠로 한 줄에 모여 고장처럼 보이지 않음. 약점: 카드마다 설명이 두 줄로 잘려 컷신 · 절전 설명이 짧아지고, 카드 기울기 때문에 글자가 아주 조금 덜 또렷함.

D10-3 · 만든 사람들 scripts/settings_panel.gd _credits · 방향 「전시회 명판」 — 제작 · 글꼴 · 엔진, 라이선스 전문은 접기

글은 게임 그대로: 레인보우 아틀리에(project.godot config/name) · 하늘을 물들이는 소녀들 · 제작 · Pastelwhale · 글꼴 · Pretendard — SIL Open Font License 1.1 · 글꼴 · Noto Sans Symbols 2 — SIL Open Font License 1.1 · 엔진 · Godot Engine — MIT License + Engine.get_license_text() 전문(MIT 고지 조건이라 빠질 수 없음, 「접기」만). 뒤로 가기: 만든 사람들 → 설정(「◀ 설정」) → 닫기.

상태

지금

설정 판 그대로 글 줄 + 바로 아래 라이선스 영문 전문이 12px 회색으로 이어짐. 제목 · 제작 · 글꼴이 모두 같은 크기라 「누가 만들었나」보다 영문 법률 글이 화면을 차지함.

A · 전시실 명판 — 액자 아래 제목 · 제작 명판, 양옆 글꼴 · 엔진, 징두리에 꽂은 안내지

비용: 벽 · 징두리 질감 + 금 액자 · 명판 · 선반 소품(방명록 · 꽃병) 부품, 키아트(assets/brand/keyart.png) 재사용. 한 화면에 다 들어가 스크롤은 라이선스 안내지 안에서만.

정직한 평: 방향 「전시회 명판」 그대로 — 이름 하나하나가 명판에 새겨져 크레딧이 「작품 소개」가 됨. 조명 · 액자 · 명판 금빛이 가장 고급스럽고, 제목 · 제작이 액자 바로 아래 큰 명판이라 순서가 분명함. 약점: 나중에 사람 이름이 늘면 양옆 명판이 모자라 벽을 다시 짜야 하고, 방명록 · 꽃병은 눌러지지 않는 장식뿐임.

B · 흐르는 크레딧 — 밤하늘을 건너는 고래 위로 글이 올라감

비용: 화면 전체 밤하늘 + 고래(whale_sd) + 워드마크. 열면 천천히 저절로 올라가고 손가락으로 밀면 멈춤(▶ 다시 = 흐름 재생). 라이선스는 「펼쳐 읽기」로 종이 창.

정직한 평: 엔딩 크레딧처럼 「한 편을 다 봤다」는 감정이 가장 큼 — 이야기 끝나고 보기에 좋음. 약점: 설정에서 잠깐 확인하려는 사람에게는 기다려야 하는 화면이고, 글이 적어 금방 끝나 「흐른다」 연출이 짧음. 정지 화면에서는 가운데 글 한 줄만 보여 셋 중 정보가 가장 적음.

C · 그림책 판권면 — 왼쪽 그림 쪽 + 오른쪽 판권 + 접힌 라이선스 낱장 추천

비용: 책 천 겉장 + 종이 두 쪽(설정 A 수첩과 다른 남색 천 · 판권 조판), 키아트 · 워드마크 재사용. 라이선스는 「낱장 펼치기」로 접힌 종이가 오른쪽 쪽 위에 펼쳐짐.

정직한 평: 글을 「판권」처럼 표로 짜 제작 · 글꼴 · 엔진 · 버전이 가장 또렷하게 읽힘. 그림이 반쪽을 채워 허전하지 않고, 라이선스 낱장의 접힌 자국이 「법률 글은 접어 둠」을 물건으로 보여 줌. 약점: 설정 A(수첩)를 고르면 「책을 펼친 판」이 두 번 이어져 비슷해 보일 수 있음(겉장 색 · 조판은 다름).

D10-4 · 소리 창 (사운드 테스트) scripts/sound_panel.gd · PD 결정 먼저: 출시 판에 「소리 듣기」로 남길지, 개발 메뉴로 옮길지

지금 코드 상태: 인벤토리 사진(출력 장치 · dB가 보이는 창)은 이미 open_dev(개발 메뉴, 디버그 빌드만)로 옮겨졌고, 출시 판 「설정 → 소리 설정」은 볼륨 두 줄만 있는 창(설정 판 볼륨 줄과 같은 내용)입니다. 그래서 정할 것은 「그 두 줄 창을 지우고 끝낼지(B)」 vs 「출시 판에 곡 · 효과음을 들어 보는 즐길 거리로 남길지(A · C)」. 곡은 game_audio.gd 2곡(bgm_stage.ogg 1:16 · bgm_battle.ogg 1:17), 효과음은 sound_table.tres 15가지 한글 이름 그대로, 수치(dB · 음높이 · 버스)는 A · C에서 숨김.

상태

지금

왼쪽: 출시 판 「설정 · 소리」 — 설정 판의 볼륨 두 줄과 똑같은 작은 창. 오른쪽: 개발 메뉴 「개발 · 사운드 테스트 · 진단」 — 출력 경로 · 지연 ms · dB · 음높이가 그대로(QA용).

A · 축음기 — 레코드 두 장 + 효과음 15가지, 수치는 숨김

비용: 축음기 그림(받침 · 나팔 · 바늘 팔 · 도는 레코드) + 레코드 재킷 2장. 재생은 지금 preview_bgm / Sfx.preview 그대로, 글만 한글 이름으로. 출시 판 설정에 「소리 듣기 ▸」 줄이 남음.

정직한 평: 곡이 2곡뿐이라도 레코드 · 나팔 덕에 「음악실」 같은 즐길 거리가 됨. 배경 음악이 꺼져 있으면 나팔에 「꺼짐」 배지 + 유나 알림으로 왜 안 들리는지 바로 알려 줌. 약점: 출시 판에 꼭 필요한 화면은 아니라 만드는 비용 대비 쓰임이 적고, 효과음 15개는 전투 밖에서 들으면 짧은 「딸깍」이라 재미가 크지 않음.

B · 개발 메뉴로 — 출시 판 설정에서 줄이 빠지고, 진단은 개발 클립보드에만 추천

비용: 가장 쌈 — settings_panel.gd의 「소리 설정」 줄과 SoundPanel.open을 지우면 끝(볼륨은 설정 판 두 줄이 이미 함). 개발 창은 모눈종이 클립보드로 판만 바꾸고 글 · 수치 · 노드 이름 그대로(release_ui_check 「developer sound window keeps the diagnostics」 통과).

정직한 평: 같은 볼륨 두 줄이 두 번 나오는 중복이 사라지고, QA 화면은 「개발 전용」 테이프로 출시 화면과 섞일 일이 없음. 약점: 출시 판에서 곡을 따로 들어 볼 곳이 없어짐(지금도 사실상 없음). 클립보드는 일부러 덜 꾸몄음 — 개발자만 봄.

C · 음악 상자 — 장미나무 상자 위 고래 인형, 곡은 구멍 뚫린 악보 띠

비용: 상자 · 뚜껑(단추 공단 안감 + 워드마크 타원 명판) · 원통 · 태엽 손잡이 + 거울 돌림판 위 고래 인형(whale_sd에 테두리빛 · 솜구름). 재생 · 정지 = 태엽 손잡이가 돌고 멈춤. A와 같이 출시 판 설정에 「소리 듣기 ▸」 줄이 남음.

정직한 평: 고래가 상자 위에서 흔들리는 장면이 귀엽고 게임 세계(하늘 고래)와 가장 잘 맞음. 악보 띠가 곡마다 다른 구멍이라 「다른 곡」이 그림으로 보임. 약점: A와 같은 이유로 출시 판 쓰임이 적고, 상자 · 뚜껑 원근이 화면 절반을 차지해 효과음 목록이 작아짐(글 13.5px).
